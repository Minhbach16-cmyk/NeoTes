Security Modules

Bộ công cụ toàn diện cho kiểm thử bảo mật web

💉

Injection Scanner

SQL Injection, XSS, Command Injection, LDAP, NoSQL — phát hiện và phân loại chính xác các lỗ hổng injection.

📁

File Inclusion

LFI / RFI / Path Traversal — kiểm tra khả năng đọc file hệ thống và thực thi file từ xa.

🔎

URL Finder

8 phương thức tìm URL có tham số: crawl, wordlist, robots.txt, sitemap, Wayback Machine.

🌐

HTTP Analysis

Phân tích request/response, headers, HTTP methods, cookie security và CORS.

🛡️

WAF Detection

Phát hiện 11 loại WAF phổ biến: Cloudflare, AWS WAF, Imperva, Sucuri, F5 BIG-IP...

🧩

Recon Module

Subdomain enumeration, technology fingerprinting, GraphQL detection, JWT analysis.

🔓

Sensitive Files

Phát hiện file nhạy cảm: .env, .git/config, wp-config.php, backup files.

📦 NeOTes v4.0.0

Công cụ quét bảo mật web — miễn phí, mã nguồn mở. Yêu cầu Python 3.8+

⬇️ Tải ZIP 🐙 Xem trên GitHub
# Clone repo $ git clone https://github.com/Minhbach16-cmyk/NeoTes.git $ cd NeoTes # Cài dependencies $ pip install requests urllib3 # Chạy tool $ python3 main.py

Tài Liệu

Hướng dẫn sử dụng nhanh

1️⃣

Quét Full

Chọn [1] trong menu → nhập URL mục tiêu → tool chạy tự động cả 28 chức năng quét.

2️⃣

Tìm URL

Chọn [2] → nhập domain → tool tìm URL có tham số bằng 8 phương thức.

📝

Báo cáo

Sau khi quét xong, tool hỏi lưu báo cáo ra file scan_report_*.txt để xem lại.

⚙️

Cấu hình

Sửa file config/wordlists.py để thêm param/file cần quét.

Câu Hỏi Thường Gặp

Những thắc mắc phổ biến

Có. NeOTes là dự án mã nguồn mở, hoàn toàn miễn phí. Bạn có thể tải, sử dụng, chỉnh sửa mà không cần trả phí.
NeOTes hỗ trợ 28 chức năng, bao gồm: SQL Injection, XSS, Command Injection, LFI, RFI, XXE, SSTI, SSRF, LDAP, NoSQL, CORS, WAF Detection, Sensitive Files, và nhiều hơn nữa.
Chỉ cần Python 3.8 trở lên và thư viện requests. Cài dependencies bằng lệnh: pip install requests urllib3. NeOTes chạy được trên Windows, Linux, macOS, Termux.
Không được phép nếu chưa có sự đồng ý bằng văn bản của chủ sở hữu. NeOTes chỉ dùng để test web của chính bạn, web có bug bounty program công khai, hoặc môi trường lab (DVWA, WebGoat...).
Có. Phiên bản v4.0.0 sử dụng baseline comparison: lấy response gốc (không payload) so với response có payload. Chỉ báo khi có sự khác biệt đáng kể, giúp giảm false positive đến 90%.
Có. NeOTes chạy tốt trên Termux (Android). Chỉ cần cài Python và requests. Đây là môi trường phổ biến để học bảo mật trên điện thoại.
Rất hoan nghênh. Bạn có thể mở Pull Request trên GitHub, báo lỗi trong tab Issues, hoặc đề xuất tính năng mới. Mọi đóng góp đều được ghi nhận.

About NeOTes

Nghiên cứu — Kiểm thử — Bảo mật

NeOTes là dự án nghiên cứu và phát triển công cụ bảo mật, tập trung vào tự động hóa quá trình kiểm thử, phân tích kết quả và xây dựng môi trường Security Lab dành cho cộng đồng nghiên cứu bảo mật tại Việt Nam.


Công cụ được thiết kế để hỗ trợ kiểm thử bảo mật trên các ứng dụng web do chính bạn sở hữu hoặc đã được cấp phép kiểm thử. Nghiêm cấm sử dụng cho mục đích tấn công hệ thống không thuộc quyền quản lý của bạn.
